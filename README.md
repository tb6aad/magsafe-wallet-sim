# MagSafe Cüzdan Simülasyonu

Tek dosyalık 3B simülasyon (`index.html`). Kurulum gerektirmez: dosyayı çift tıklayıp tarayıcıda açabilir ya da GitHub Pages ile yayınlayabilirsin.
three.js ve yazı tipleri internetten (cdnjs ve Google Fonts) yüklenir, bu yüzden internet bağlantısı gerekir.

## GitHub Pages ile yayınlama
1. GitHub'da yeni bir depo aç (ör. `magsafe-wallet-sim`) ve `index.html` ile bu `README.md` dosyasını yükle.
2. Depoda **Settings → Pages** bölümüne git.
3. **Build and deployment → Source** için **Deploy from a branch**, branch için `main`, klasör için `/ (root)` seç ve kaydet.
4. Bir iki dakika sonra adres hazır olur:

   `https://<kullanıcı-adın>.github.io/magsafe-wallet-sim/`
